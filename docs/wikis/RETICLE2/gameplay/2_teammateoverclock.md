When in single player mode, each squad member will activate their OC ability autonomously at various levels, like Code Vein. The player can activate them manually by swapping into the character, activating the ability, then swapping back out. 

Teammates can have teamwide OC abilities whose effects stack with the the active characters OC abilities. For instance, a teamwide firerate buff can stack with a personal attack buff.
